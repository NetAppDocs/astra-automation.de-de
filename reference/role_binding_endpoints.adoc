= Astra API (ACC) Rollenbindungs-Endpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Verwaltung der Rollenbindungen, die Benutzern oder Gruppen in einem Konto Berechtigungen erteilen. Eine Rollenbindung verknüpft einen Benutzer oder eine Gruppe mit einer Rolle.

Die Role Binding API beschreibt die Beziehungen zwischen den Benutzer-Konto-Paaren bzw. Gruppen-Konto-Paaren sowie die ihnen zugewiesenen Berechtigungen (Rollen).
