= Astra API (ACC) ASUP-Endpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Erstellung von AutoSupport (ASUP) Bundles und optionales Hochladen auf NetApp zur Unterstützung bei der Fehlerbehebung.

Die ASUP-API ermöglicht den Zugriff auf ASUP-Ressourcen, um die AutoSupport-Bundles zu erstellen und optional hochzuladen.
