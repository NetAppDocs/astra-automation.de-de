= Astra API (ACC) Benachrichtigungsendpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Für jeden Benutzer lassen sich die Ereignisse anzeigen, die an ein Benachrichtigungsziel weitergeleitet werden.

Die Notification API bietet pro Benutzer Zugriff auf Ereignisse mit einem Benachrichtigungsziel.
