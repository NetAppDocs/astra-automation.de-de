= Gruppe löschen
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Löscht die angegebene Gruppenressource. Damit lässt sich eine Gruppe zusammen mit den zugehörigen Rollenbindungen aus dem System entfernen.



[[http-method-and-endpoint]]
== HTTP-Methode und -Endpunkt

[.api-doc-operation .api-doc-operation-delete]#LÖSCHEN# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}`#



[[usage-notes]]
== Nutzungshinweise

Entfernt die angegebene Group-API-Ressource.

*Nebenwirkungen*

* Die folgenden Ressourcen, die der Gruppe zugeordnet sind, werden gelöscht:
* Rollenbindungen, die sich auf die Gruppe beziehen




[[parameters]]
== Parameter

[cols="5*"]
|===
| Name | Typ | In | Erforderlich | Beschreibung 


| Konto-ID | Zeichenkette | Pfad | Wahr  a| 
ID der übergeordneten Kontoressource

* Beispiel: {{.Account}}




| Gruppen-ID | Zeichenkette | Pfad | Wahr  a| 
ID der aufzulistenden Gruppensammlung

|===
