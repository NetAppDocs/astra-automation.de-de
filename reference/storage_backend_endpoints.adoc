= Astra API (ACC) Speicher-Backend-Endpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Storage Backends managen, also die Anbieter von Storage Services, die Ihre verwalteten Cluster und Applikationen nutzen können.

Die Storage Backend API bietet Zugriff auf Repräsentationen von Anbietern von Speicherdiensten (Storage-Backends), die von verwalteten Clustern und Anwendungen genutzt werden können.
