= Astra API (ACC) Metrik-Endpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Abrufen von Metriken für ein Astra Control Konto zur Überwachung seiner Aktivität und Ressourcennutzung.
