= Astra API (ACC)-Paket-Endpunkte
:allow-uri-read:

[role="lead"]
Sie managen die in Astra Control registrierten installierbaren Softwarepakete. Die registrierten Pakete bestimmen, welche Upgrades verfügbar sind.

Die Package-API repräsentiert installierbare Softwarepakete.
