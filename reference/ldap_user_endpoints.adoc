= Astra API (ACC) LDAP-Benutzerendpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Anzeige der Benutzer auf dem konfigurierten Lightweight Directory Access Protocol (LDAP)-Server. Diese Endpunkte sind schreibgeschützt.

Die LDAP-Benutzer-API ermöglicht den Lesezugriff auf LDAP-Benutzer innerhalb des konfigurierten LDAP-Servers.
