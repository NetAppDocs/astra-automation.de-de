= Astra API (ACC) Aufgabenendpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Hier werden die von Astra Control verfolgten lang laufenden Aufgaben angezeigt, sodass ihr Fortschritt überwacht werden kann.

Die Task App API ermöglicht den Zugriff auf verwaltete Aufgabenressourcen, um langlaufende Aufgaben darzustellen.
