= Astra API (ACC) Ereignisendpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Die in Astra Control auftretenden Ereignisse ermöglichen die Nachverfolgung der Systemaktivität.

Die Event-API ermöglicht den Zugriff auf Ereignisse, die im System auftreten.
