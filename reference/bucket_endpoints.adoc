= Astra API (ACC) Bucket-Endpunkte
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Management der Buckets, die Astra Control zum Speichern von Applikations-Backups verwendet.

Die Bucket-API ermöglicht den Zugriff auf Buckets, die zum Speichern von Anwendungs-Backups in Astra verwendet werden.
